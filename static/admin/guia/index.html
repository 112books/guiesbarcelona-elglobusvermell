1. Accés a l'editor

L'editor funciona amb un token personal de GitHub (PAT). És una clau d'un sol ús que identifica el teu usuari sense necessitat de contrasenya.

Primera vegada: crear el token

  1. Entra a GitHub → Settings → Tokens (classic).
  2. Al camp Note, posa un nom descriptiu, per exemple Editor Guies Barcelona.
  3. A Expiration, tria Custom i posa la data final (End date) d'aquí a un any.
  4. A Select scopes, marca la casella public_repo (la trobaràs a la primera taula, una mica per sota de la casella gran repo). És l'única que cal: dona accés de lectura i escriptura als repositoris públics on el teu compte ja pot entrar.
  5. Clica Generate token i copia el token (comença per ghp_ i apareix una sola vegada).
Desa el token en un lloc segur (gestor de contrasenyes o nota privada). Si el perds hauràs de crear-ne un de nou seguint els mateixos passos.
Per què el token clàssic i no el fine-grained? El projecte viu en un compte personal de GitHub, i els tokens fine-grained només funcionen amb repositoris propis o d'organitzacions de les quals ets membre. El token clàssic amb permís public_repo funciona per a tots els convidats al projecte i només pot tocar repositoris públics.

Entrar a l'editor

  1. Ves a l'editor: 112books.github.io/guiesbarcelona-elglobusvermell/admin/cms/ (quan el domini propi estigui actiu, serà guiesbarcelona.elglobusvermell.org/admin/cms/).
  2. Enganxa el token al camp i clica Iniciar la sessió amb un testimoni d'accés (en anglès, Sign in using Access Token).
  3. L'editor carrega la llista d'edificis.

2. La llista d'edificis

Un cop dins l'editor, veuràs la col·lecció Edificis i elements. Conté tots els edificis del mapa, organitzats per publicació.

Filtrar per publicació

Al menú de la dreta (View) pots agrupar els edificis per guia: GATCPAC, Arquitectura Moderna, La Barceloneta, etc. Cada edifici apareix en tants grups com guies té assignades.

Filtrar per estat

Al mateix menú pots filtrar per Publicats (visibles al web) o Esborranys (ocults).

Cercar

Fes servir el camp de cerca a la barra superior per trobar un edifici per nom o adreça.

3. Editar un edifici

Clica el nom d'un edifici per obrir-ne la fitxa. Modifica els camps que calgui i desa els canvis.

Els canvis es guarden directament al repositori de GitHub. En 1-2 minuts el web s'actualitza automàticament.

4. Descripció dels camps

Camp Descripció
Títol obligatori Nom oficial de l'edifici. Apareix al mapa i a la fitxa.
Esborrany Si està activat, l'edifici no apareix al web. Útil per preparar fitxes incompletes.
Fotografia opcional Fotografia principal (portada) de l'edifici. Si no n'hi ha, el web mostra un espai reservat ("Imatge pendent").
Més fotografies opcional Fotos addicionals a la principal. Si n'hi afegeixes alguna, la fitxa de l'edifici mostra un carrusel al web (fletxes per canviar d'imatge, o lliscar amb el dit al mòbil).
Publicacions opcional Guia(es) on apareix l'edifici. Un edifici pot estar a diverses guies alhora.
Temes transversals opcional Categories que creuen publicacions: Espai públic, Art públic, Dones arquitectes, Nomenclàtor femení.
Adreça opcional Adreça postal completa. Exemple: Carrer de Provença, 261.
Any de construcció opcional Any o període. Exemples: 1934, c. 1930, 1928-1931.
Arquitectes opcional Un nom per línia. Exemple: Josep Lluís Sert.
Tipologia opcional Exemple: Habitatge col·lectiu, Equipament cultural, Espai públic.
Nivell de protecció opcional Del Catàleg del Patrimoni Arquitectònic de Barcelona. Nivells A (BCIN) fins a D (Documental).
Superfície (m²) opcional Superfície construïda en metres quadrats (número enter).
Anys de reforma opcional Un any per línia, per a reformes o rehabilitacions significatives.
Premis opcional Un premi per línia. Exemple: Premi FAD 1998.
Latitud / Longitud opcional Coordenades GPS per situar l'edifici al mapa. Exemples: 41.3851 / 2.1734. Sense coordenades, l'edifici no apareix al mapa.
Descripció opcional Text descriptiu principal de la fitxa. Text pla, sense format.
Text nomenclàtor femení opcional Només per als elements de la categoria Nomenclàtor femení.
Contingut addicional opcional Text enriquit (negreta, llistes, enllaços). Apareix a continuació de la descripció.
Galeria de fotos: per veure d'un cop d'ull quins edificis tenen foto i quins no, fes servir la Galeria de fotos (enllaç també al panell principal de l'administrador). Cerca, filtra per "amb foto"/"sense foto", i clica una fitxa per obrir-la directament a l'editor.

5. Editar les pàgines del web

A la barra lateral esquerra de l'editor, sota Pàgines del web, trobaràs:

  • Presentació: text de la pàgina principal (inici del web).
  • En paper: descripció de les publicacions físiques.
  • Crèdits: autors, col·laboradors i agraïments.

Les pàgines s'editen amb un editor de text enriquit (negreta, llistes, enllaços, etc.).

Pàgines de plànol-guia

Sota Plànols-guia trobaràs el contingut de cada pàgina de mapa (GATCPAC, Mercats, Biblioteques...): text introductori, bibliografia, "Altres biblioteques", etc. S'edita igual, amb text enriquit.

No esborris ni canviïs el nom dels títols "Llistat" ni "Bibliografia Relacionada" (## dins el text): són seccions especials que el web reconeix pel seu nom exacte per mostrar-hi el llistat d'edificis i la bibliografia correctament.

6. Desar i publicar

  1. Modifica els camps que calgui.
  2. Clica el botó Save (a la part superior dreta).
  3. El canvi es puja directament a GitHub. En 1-2 minuts el web reflecteix la modificació.
No cal fer cap pas addicional: desar equival a publicar. Si vols preparar una fitxa sense publicar-la, activa el camp Esborrany.
Avís sobre el format intern: el primer cop que desis una fitxa, el seu fitxer intern es reordena (ordre dels camps, llistes amb sagnat, camps opcionals buits que s'hi afegeixen). És normal i no té cap efecte al web: els continguts queden exactament iguals.

7. Preguntes freqüents

Com creo un punt nou al mapa?

No es pot fer directament des d'aquest editor: crear un edifici nou requereix coordinació tècnica (per mantenir la qualitat i evitar duplicats). Contacta amb l'equip tècnic i us el creen correctament.

Com esborro un punt del mapa?

No s'ha d'eliminar mai un edifici des de l'editor. Activa el camp Esborrany: desapareix del web immediatament, però les dades queden guardades per si cal recuperar-lo més endavant.

Com poso les coordenades d'un punt si l'adreça postal no funciona bé?

Obre Google Maps, busca el lloc exacte i fes clic dret sobre el punt al mapa. Apareixeran unes coordenades com 41.3851, 2.1734 — el primer número és la Latitud, el segon la Longitud. Copia'ls al camp corresponent de l'editor.

Per què el meu edifici no apareix al mapa?

Comprova dues coses: que el camp Esborrany no estigui activat, i que hi hagi valors a Latitud i Longitud. Sense coordenades, l'edifici existeix però no es pot situar al mapa.

M'he equivocat desant un canvi. Puc desfer-ho?

Sí: torna a obrir la fitxa i corregeix el camp amb el valor correcte, i torna a desar. Si necessites recuperar una versió anterior exacta (l'historial complet queda guardat a GitHub), contacta amb l'equip tècnic.

El token ha deixat de funcionar. Què faig?

Els tokens caduquen (vas triar una durada d'1 any en crear-lo). Torna a seguir els passos de la secció 1. Accés a l'editor per crear-ne un de nou.

8. Que NO fer

No creïs edificis nous des d'aquest editor. La creació de nous elements requereix coordinació tècnica.
No eliminis edificis. Si un element ha de desaparèixer del web, activa el camp Esborrany en lloc de suprimir-lo.
  • No canviïs el nom del fitxer (slug) d'un edifici: trencaries els enllaços existents.
  • No toquis els camps de coordenades si no estàs segur/a dels valors correctes.
  • No posis format markdown (asterisc, guions, corxets) al camp Descripció: utilitza el camp Contingut addicional per a text enriquit.
