Com crear contingut nou (una fitxa d'edifici nova)

Hi ha dos editors, tots dos a GitHub Pages mentre no fem el tall del domini:

  • Editar el que ja existeix — 112books.github.io/guiesbarcelona-elglobusvermell/admin/cms/ (fitxes existents, pàgines, plànols-guia i arquitectes; no permet crear fitxes noves).
  • Crear contingut nou — 112books.github.io/guiesbarcelona-elglobusvermell/admin/cms-admin/ (el mateix, amb el botó per afegir una fitxa nova).
  1. Entra a l'editor d'administració i inicia sessió amb el teu token (el mateix d'ara).
  2. A la banda esquerra, tria Edificis i elements.
  3. Clica Afegir, a dalt del llistat.
  4. Omple com a mínim Títol, Publicacions (el o els plànols on surt) i les coordenades Latitud i Longitud. Sense coordenades, la fitxa no apareix al mapa.
  5. Desa. El web es reconstrueix sol en dos o tres minuts.

El token és el clàssic amb permís public_repo. Quan el domini propi estigui actiu, les adreces passaran a guiesbarcelona.elglobusvermell.org/admin/cms/ i .../admin/cms-admin/.
