El web original d'arquitectura (guiesbarcelona.elglobusvermell.org/arquitectura-i-urbanisme/) mostra simultàniament "© copyright" i "CC BY-SA 4.0", que és contradictori.

**Why:** Les dues llicències son incompatibles — copyright reserva tots els drets, CC BY-SA 4.0 en cedeix molts. Cal decidir quina s'aplica realment.

**How to apply:** Quan es parli de continguts, llicència o footer amb El Globus Vermell, recordar que cal aclarir aquest punt. Al web nou, de moment hem posat el footer amb "© 2026 Guies Barcelona" + badge CC BY-SA 4.0 — igual que l'original, però cal consulta legal/client per determinar si el contingut és sota copyright o CC.
