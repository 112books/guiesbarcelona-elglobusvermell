### Decisions tècniques
- **toml-to-yaml.py via PyYAML**: Reescrit per usar `yaml.dump()` en lloc de construcció manual de YAML. Gestiona correctament `[[intervencions]]` (TOML array of tables → llista de dicts YAML). Alternativa manual hauria requerit molts casos especials.
- **format yaml-frontmatter al CMS**: La migració TOML→YAML era imprescindible perquè Sveltia CMS amb `format: yaml-frontmatter` simplement no mostra els fitxers TOML (`No entries found`).
- **AUB_09 = masies, AUB_10 = biblioteques**: Inferit per ordre de publicació en el web de producció. Podria ser a l'inrevés — no verificat definitivament.
- **logo_url → GitHub raw**: La URL de producció no funciona en staging (el domini no serveix la imatge des d'un staging en un subpath). La URL raw de GitHub (`raw.githubusercontent.com`) funciona des de qualsevol entorn.
- **Pseudo-fullscreen CSS per iOS**: `position:fixed` amb `100dvh` (dynamic viewport height, correcte per iOS Safari que oculta la barra de navegació). `map.invalidateSize()` amb timeout perquè Leaflet recalculi les tiles.

### Deute tècnic acceptat
- **"No entries found" CMS**: Pendent que l'usuari netegi la caché del navegador. No és un bug de codi.
- **AUB_09/AUB_10**: Si masies i biblioteques estan intercanviades al CMS, cal corregir manualment (renombrar les imatges).
- **Intervencions vs anys_reforma**: `intervencions` és l'estructura rica (tipus+autors+any+desc) dels fitxers antics; `anys_reforma` era el camp simple del schema. Ara coexisteixen. Caldria una decisió sobre quin camp usar definitivament.
