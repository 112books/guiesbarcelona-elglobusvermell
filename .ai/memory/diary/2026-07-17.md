### Decisions tècniques
- **staticrypt + document.write bloqueja scripts externs**: Chrome no executa scripts externs carregats via `document.write` en certes condicions. Confirmat desactivant staticrypt.
- **Pedaç inline height**: `style="height:28rem"` directament al div del mapa. Cutre però funcional fins que es resolgui staticrypt.
- **Estategy staging**: Home provisional sense JS complex mentre es busca alternativa a staticrypt (HTTP Basic Auth a Dinahosting quan s'hagi de fer la migració a producció).
- **SSH en lloc de HTTPS per git push**: Token expirat + GitHub 503. SSH amb claus existents funciona sense tokens.

### Deute tècnic acceptat
- Inline height al div del mapa (`style="height:28rem"`) — a eliminar quan es resolgui staticrypt
- Template personalitzat staticrypt creat però no desplegat (`.staticrypt-template.html`)
- Mapa a la home desactivat temporalment (pàgina provisional)
