### Decisions tècniques
- **`detectRetina: true` revertit**: CartoDB no serveix tiles `@2x` amb la URL configurada. El mapa quedava en blanc. `updateWhenZooming: false` és suficient i segur.
- **Punt `::before` eliminat**: l'indicador de color és el fons del botó quan és actiu. El punt creava asimetria visual (1.55rem davant text vs 0.65rem darrere). Coherent amb el botó "Tots".
- **`label` → `span` per grups de botons**: `<label>` no s'associa semànticament a grups de botons. `role="group" aria-labelledby` és la semàntica correcta.
- **`--header-actual-height` via JS**: solució neta sense modificar on s'aplica la classe `is-scrolled`. La variable CSS es propaga a tot el DOM des de `:root`.

### Deute tècnic acceptat
- Cap nou.

### Decisions tècniques
- **Staticrypt → robots.txt + noindex**: La "protecció" de staticrypt era feble (repo públic). Substitució neta: robots.txt bloqueja tots els motors i bots IA. Meta noindex/noai com a capa addicional. Cap contrasenya = cap interferència amb JS/CSS.
- **Fullscreen natiu en lloc de plugin**: Fullscreen API suportada a tots els browsers moderns. Evita dependència externa. invalidateSize() amb setTimeout(100) perquè Leaflet recalculi tiles un cop el browser ha completat la transició.
- **Falsos positius agent Explore**: L'agent va identificar erròniament "85 fitxers amb (41,2)" (0 reals), anys malformats (eren strings YAML vàlids), i títols problemàtics (cometes dobles vàlides en YAML). Important verificar sempre els findings d'agents amb grep directe.

### Decisions tècniques
- **Hub en lloc de CMS directe**: /admin/ ara és un portal; el CMS és una eina entre d'altres. Extensible fàcilment amb noves targetes (futur: backups, deploy manual, etc.).
- **analytics.json a `static/` (no `data/`)**: `data/` a Hugo no es serveix com a fitxers estàtics, només per a templates. El dashboard és JS pur que fa fetch → necessita URL accessible → `static/admin/stats/analytics.json`.

- **Contrasenya dashboard**: `guiesbarcelona2026` (SHA-256 hardcoded). El staging no té auth de xarxa → la contrasenya és la barrera. Fàcil de canviar: `echo -n "nova" | sha256sum` i editar el `pwHash`.
- **by_lang buit**: La API de GoatCounter no exposa directament l'idioma del navegador. El camp `by_lang` s'omple com `{}`. El dashboard ho gestiona correctament mostrant "sense dades d'idioma".

### Deute tècnic acceptat
- **OAuth CMS definitiu**: api.netlify.com retorna 404 per a sites no registrats a Netlify. GitHub OAuth queda desactivat fins que Dinahosting estigui llest (Fase 1: servidor OAuth PHP propi).
- **by_lang**: GoatCounter no té endpoint d'idioma de navegador. Si es vol en un futur, caldria parsejar Accept-Language des del propi tracking script.
