## Tasques completades

### 1. Fix crèdit CC BY-SA 4.0 a les fotos (fitxes d'edifici)
El `<figcaption>` amb el crèdit fotogràfic no era visible. Causa: CSS `overflow: hidden` + `aspect-ratio: 1/1` al contenidor pare clippejava tot el que sobrés de la imatge. Fix: moure `aspect-ratio: 1/1` a l'`<img>` i posar `overflow: visible` al `<figure>`. Aplicat a `main.css` (ambdues còpies del tema).

### 2. Estadístiques GoatCounter — fix definitiu
Dos bugs encadenats causaven que el dashboard sempre mostrés zeros:
- **Bug 1:** `build-stats.py` escrivia zeros al JSON si l'API de GoatCounter fallava o retornava 0 visites. Fix: funció `preserve_existing()` que manté les dades anteriors en cas d'error.
- **Bug 2 (l'important):** GitHub Actions per disseny no permet que workflows que fan push via `GITHUB_TOKEN` activin altres workflows (prevé bucles en cascada). Tots els commits automàtics d'estadístiques s'emmagatzemaven al repo però mai desplegaven. Fix: afegir `gh workflow run deploy-prod.yml --ref main` explícit al `goatcounter.yml` quan hi ha canvis.
- Cron baixat de cada hora (24x/dia) a cada 6 hores (4x/dia).
- Retry loop afegit al `deploy-prod.yml` per al wget de Hugo (3 intents, error exit code 4 era transitori).
