### Decisions tècniques

- **`color-mix()` per a colors dinàmics de publicació**: els colors de publicació (`--pub-color`) s'usen com a text i fons en diversos elements. No es pot corregir el contrast cas a cas perquè el color és un CSS custom property injectada per Hugo. `color-mix(in srgb, var(--pub-color), #000 N%)` barreja el color amb negre sense canviar el disseny visual de forma dràstica — la variant 45% per a text i 20% per a fons amb text blanc.
- **pa11y en CI executa sobre el server de staging**: el build previ `hugo --minify --environment staging` és una verificació de build, però el pa11y s'ha de fer sobre el server en viu (no sobre els fitxers estàtics) perquè el `.pa11yci.json` usa URLs amb el subpath de staging.

### Decisions tècniques

- **Ruta Claude projects codificada automàticament**: la ruta `~/.claude/projects/` afegeix el path del repo amb `/` substituïts per `-`. El script la deriva a runtime amb `REPO_ROOT="${REPO_ROOT//\//-}"`, sense hardcoding.
- **rsync --delete en ambdues direccions**: garanteix que els fitxers eliminats en un ordinador no persisteixin a l'altre. El repo és la font de veritat.
- **Stop hook fa git pull --rebase primer**: evita conflictes si dos ordinadors han empès canvis entremig. Si el pull falla (offline), el hook surt silenciosament (`|| true`).
- **Hooks en .claude/settings.json del projecte (no global)**: el settings es commita al repo, de manera que tots els ordinadors que clonin el projecte tindran els hooks automàticament.

### Deute tècnic acceptat

- Si dos ordinadors tanquen sessió simultàniament i tots dos fan push, el segon fallarà silenciosament (el `|| true` del hook absorbeix l'error). La memòria de l'últim a empènyer guanyarà al proper `import`. Acceptable per a un ús personal d'un sol usuari.
