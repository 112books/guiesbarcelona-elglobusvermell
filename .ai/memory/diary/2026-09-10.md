### Decisions tècniques

- **`color-mix()` per a colors dinàmics de publicació**: els colors de publicació (`--pub-color`) s'usen com a text i fons en diversos elements. No es pot corregir el contrast cas a cas perquè el color és un CSS custom property injectada per Hugo. `color-mix(in srgb, var(--pub-color), #000 N%)` barreja el color amb negre sense canviar el disseny visual de forma dràstica — la variant 45% per a text i 20% per a fons amb text blanc.
- **pa11y en CI executa sobre el server de staging**: el build previ `hugo --minify --environment staging` és una verificació de build, però el pa11y s'ha de fer sobre el server en viu (no sobre els fitxers estàtics) perquè el `.pa11yci.json` usa URLs amb el subpath de staging.
