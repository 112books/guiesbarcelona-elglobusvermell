Commits sempre individuals per tasca (un commit = una tasca TXX).
Deploys (push) agrupats per tasques similars, no per cada commit.

**Why:** Facilita la revisió de canvis i permet revertir tasques individualment si cal.
**How to apply:** Cada TXX té el seu commit propi. El push es fa quan s'acaba un grup de tasques relacionades.
