# ARQUITECTES-URLS.md — Tasca de recerca d'URLs

## Objectiu

Cercar les URLs de perfil de cada arquitecte o estudi a:
1. **Arxiu COAC** (arquitecturacatalana.cat) — prioritari
2. **Viquipèdia en català** (ca.wikipedia.org) — complementari

## Format de resposta

Per a cada arquitecte, retorna exactament:

```
Nom: [nom tal com apareix aquí]
COAC: [URL completa o "no trobat"]
Wikipedia: [URL completa o "no trobat"]
```

## Instruccions

- URLs de COAC: busca a https://www.arquitecturacatalana.cat/ca/autors/[slug]
  (el slug sol ser el nom en minúscules, sense accents, amb guions)
  Exemple: MBM Arquitectes → https://www.arquitecturacatalona.cat/ca/autors/mbm-arquitectes
- URLs de Viquipèdia: busca a https://ca.wikipedia.org/wiki/[Nom]
- Si un nom és clarament un col·lectiu o signatura combinada (ex: "Oriol Bohigas i Josep Maria Martorell"), 
  cerca cada arquitecte per separat — el sistema els registra per separat.
- Si no trobes cap URL, posa "no trobat".
- No inventes URLs. Si no n'estàs segur, posa "no trobat".
