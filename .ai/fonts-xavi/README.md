# Fonts Xavi — missatges originals (font de veritat)

Aquí es guarden els correus/missatges originals d'en Xavi **literalment**, sense
parafrasear ni resumir. Són la font de veritat per citar cada tasca.

## Conveni de nom

`YYYY-MM-DD-assumpte-curt.md`

Cada fitxer ha de començar amb una capçalera amb:
- **De:** Xavi (correu)
- **Data:** (tal com consta al missatge)
- **Assumpte:**
- **Cos:** el text exacte, sense editar.

Si un mateix correu tracta diversos temes, es guarda sencer i aleshores
s'enllaça des de cada tasca a la part concreta (no es talla el correu).

## Relació amb els resums

Els fitxers consolidats (p. ex. `.ai/FEEDBACK-XAVI-2026-09-30.md`) són **derivats**:
serveixen per indexar i prioritzar, però davant de qualsevol dubte mana el text
original d'aquesta carpeta.

## Regla de treball

1. Cada nota de `.ai/canvis/` inclou una secció **"Text literal de Xavi"** amb la
   cita exacta i l'enllaç al fitxer font d'aquesta carpeta.
2. Si una petició és ambigua (p. ex. T07 "eliminar" vs "moure", o com ha de
   funcionar el cercador de T06), es pregunta a Xavi abans de decidir.
